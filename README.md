# 🌱 成长手册 - 家庭互动小程序

一个适用于手机、平板和电脑的家庭互动 Web 应用（PWA），帮助家庭成员记录生活、管理账务、分工家务、表达情感。

## ✨ 功能特性

### 1. 📸 家庭相册
- 支持图片和视频上传
- 图片自动压缩，节省存储空间
- 拖拽上传，多文件同时上传
- 网格展示，点击预览
- 记录上传者和上传时间

### 2. 🧾 家庭账单
- 11 种费用分类（水费、电费、燃气、物业、保险、汽车养护、生活采购、医疗、教育、通讯、其他）
- 月度切换，查看历史账单
- 分类统计，一目了然
- 每个成员都可记录自己支付的家用

### 3. 💰 收支明细
- 记录每位成员的月度收入与支出
- 收入/支出分类管理
- 按成员分组展示，家庭公开透明
- 月度汇总，收支结余一目了然

### 4. 🧹 家务分工
- 17 种家务类型（买菜、洗碗、做饭、洗衣服、洗车、扫地、拖地等）
- 每日家务记录
- 月度贡献排行榜，进度条可视化
- **智能分配**：根据历史贡献加权随机分配家务，做家务少的人更容易被选中
- 家务类型分布统计

### 5. 🤝 家庭外交
- 记录婚宴、白事、生日宴、满月宴、聚餐等各类人情往来
- 礼金收支方向记录（送出/收入）
- 对方信息、活动日期、备注
- 礼金收支总额统计

### 6. 💬 情绪社区
- 8 种心情标签（开心、感恩、难过、生气、道歉、兴奋、爱意、感慨）
- 发布动态抒发情感
- 可以 @ 特定家庭成员（例如向某人道歉）
- 点赞和评论互动

### 7. 📝 家庭备忘录
- 创建任务备忘、重大事项、突发状况记录
- 紧急/普通优先级
- 截止日期设置
- 可指定提醒对象（给自己或家人）
- 勾选完成、已完成列表

## 📱 跨平台支持

- **手机端**：底部导航栏 + 侧滑菜单
- **平板端**：自适应布局
- **电脑端**：侧边栏导航
- **PWA**：可安装到手机桌面，全屏体验

## 🚀 快速开始

1. 直接用浏览器打开 `index.html` 即可使用
2. 首次使用会自动创建默认成员（爸爸、妈妈、孩子）
3. 在「设置」页面可以：
   - 切换当前身份
   - 添加/编辑/删除家庭成员
   - 修改应用名称和家庭名称
   - 导出/导入数据备份
   - 清空所有数据

## 💾 数据存储

所有数据保存在浏览器本地存储（localStorage）中，无需服务器。建议定期使用「导出数据」功能备份。

## 🛠️ 技术栈

- 纯原生 HTML/CSS/JavaScript，无框架依赖
- localStorage 本地存储
- PWA (Progressive Web App) 可安装
- 响应式设计，适配所有设备

## 📝 自定义修改

- **修改应用名称**：在「设置 → 应用设置」中修改
- **修改主题色**：编辑 `css/styles.css` 中的 `:root` CSS 变量
- **添加家务类型**：编辑 `js/modules/chores.js` 中的 `choreTypes` 数组
- **添加账单分类**：编辑 `js/modules/bills.js` 中的 `categories` 数组
- **添加心情标签**：编辑 `js/modules/community.js` 中的 `moods` 数组
